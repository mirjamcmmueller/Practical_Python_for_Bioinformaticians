# Practical Python for Bioinformaticians
*29.05.2026, Mirjam Müller*

Hi! 

If you are looking for a thorough, textbook-like python introduction, keep looking. This is not it. 
Instead, this is a set of practical skills (with as many print commands as possible for visualization), for those that struggle to get started with python and feel overwhelmed by the abstract concepts.
It is not perfect and by no means a textbook. 

As Bioinformaticians, python can be a very useful tool, especially to parse and process biological files, such as outputs from various softwares or database/sequencing files.
But it can also be incredibly overwhelming when freshly starting, as the language is not quite "intuitive". 

I structured this into a series of different jupyter notebooks, chosen because you can run code right after the explanation and see what it prints for easy visualization. If you are not familiar jupyter notebook, you can find an explanation on how to open them in [VSCode](https://code.visualstudio.com/download) [here](How_to_Jupyter_Notebook.md).

The notebooks are structured to be built on the previous topics, so if you feel lost at any point, the answer should be in a previous notebook. 

- [01 Introduction](01_intro.ipynb)
- [02 Variables and other basics](02_variables_types_printing.ipynb)
- [03 How to read error messages and debug](03_debugging_and_tracebacks.ipynb)
- [04 Strings and how to manipulate them](04_strings_indexing_slicing.ipynb)
- [05 Lists, Dictionaries, Sets and Tuples](05_lists_dicts_sets_tuples.ipynb)
- [06 Loops and Conditions](06_loops_conditions.ipynb)
- [07 File handling](07_file_handling.ipynb)
- [08 Working with biological files](08_fasta_tsv_parsing.ipynb)
- [09 How to write your own functions](09_functions.ipynb)
- [10 How to run a script from command line and use input arguments](10_command_line_scripts.ipynb)
- [11 Pandas](11_pandas_basics.ipynb)
- [12 Other useful packages](12_useful_packages_and_next_steps.ipynb)

I hope this helps someone and if nothing else, at least makes python seem less intimidating. 

Good luck!
